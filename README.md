# Logistic Regression Project

This project uses logistic regression on two Kaggle datasets and has a user interface built with Gradio and Flask.

## Datasets
1. Water Potability (water_potability.csv) - predicts if water is safe to drink
2. Heart Failure Prediction (heart.csv) - predicts if heart disease is likely

## Files
- notebook.ipynb - full code (training, Gradio and Flask)
- water_potability.csv - water dataset
- heart.csv - heart dataset

## How to run
1. Install the libraries: pip install pandas scikit-learn gradio flask
2. Put the notebook and both CSV files in the same folder
3. Open the notebook in Jupyter and run the cells in order

## Results
The models are checked with Accuracy, MSE, MAE and R2.
Accuracy of water model: 0.6280487804878049
Accuracy of heart model: 0.7391304347826086
## Tools used
Python, pandas, scikit-learn, Gradio, Flask
